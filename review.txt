Q1 Explain Node.js architecture and single-threaded model.
Answer--> Node.js work on event driven architecture.It uses single threaded model to handle multiple request using event loop, callback queen and  asyn-await without creating thread for every request. When a request made, Node.js deliever it to the system and continues handling other requests.

Q3 Explain request handling in Express including query parameters and request body parsing.
Answer--> In Express.js, request handling is done using routes and middleware. A route defines how the server responds to a specific client request (such as GET, POST, PUT, DELETE).When a client sends a request, Express processes it and returns a response.
1. Query Parameters:Query parameters are values passed in the URL after a question mark
2. Request Body Parsing:Request body contains data sent by the client, mainly in POST or PUT requests.
